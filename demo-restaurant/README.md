# Atelier Noir – Restaurant-Demo

Fiktives Premium-Portfolio-Projekt von Gery Webdesign.

Seiten: Startseite, Speisekarte, Einblicke/Galerie, Reservierung.

Die Reservierungsanfrage öffnet das E-Mail-Programm und verwendet eine Platzhalteradresse. Für echten Betrieb sind echte Kontaktdaten, rechtliche Pflichtangaben, Datenschutz und ein sicherer Versand-/Reservierungsdienst nötig. Bilder werden derzeit über Unsplash-URLs geladen und benötigen eine Internetverbindung. Alle Gerichte und Preise sind Beispieldaten.

## Datenschutz

Schriften (DM Sans, Playfair Display) liegen lokal in `fonts/`, die Fotos (Unsplash-Lizenz) lokal in `img/`. Die Hell/Dunkel-Wahl (`an-theme`) wird nur im sessionStorage gespeichert.
